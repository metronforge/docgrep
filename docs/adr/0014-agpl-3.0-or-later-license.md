# ADR-0014: License under AGPL-3.0-or-later

**Status:** Accepted
**Date:** 2026-10-04

## Context

The project declared Apache-2.0 at the start. The PDF backend PyMuPDF is distributed under AGPL-3.0 (or a commercial licence), and docgrep imports it. A combined work that includes an AGPL-3.0 library can only be distributed under terms compatible with the AGPL.

## Decision

docgrep is licensed under AGPL-3.0-or-later. LICENSE holds the unmodified licence text and the package metadata declares the SPDX identifier `AGPL-3.0-or-later`.

## Consequences

Using, studying and modifying docgrep for your own purposes, alone or inside an organisation, imposes no obligation to publish anything. The obligations arise when copies are distributed, or when people other than the operator interact with a modified version over a network: they must be offered the corresponding source of that version. Other dependencies keep their own licences. Relicensing later requires the consent of all copyright holders, so external contributions should be accepted with that in mind. If the PDF backend is ever replaced by a permissively licensed one, this decision can be revisited in a new ADR.
